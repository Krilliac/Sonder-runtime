Unattended asks are refused at step 5c of _decide. The effect classes
(mutation, execution, dangerous) fail closed when no operator is
attending; ask-class reads proceed on the record. Each refusal leaves
a content-free receipt in operations.db and names the call it refused,
so /approve <call id> can let exactly that call run once.
