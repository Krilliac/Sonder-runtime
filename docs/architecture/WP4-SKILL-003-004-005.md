# WP4 SKILL-003/004/005 — refresh, trust, and plugin-lite manifests

Skill refresh decisions are digest- and trust-bound, with incompatible or
untrusted candidates rejected. Plugin-lite manifests are declarative metadata
only: capabilities, permissions, dependencies, and runtime compatibility are
validated without importing or executing plugin code.

Evidence: `tests/test_skill_refresh_plugin_manifest.py`, architecture/evidence
gates, and compileall.
