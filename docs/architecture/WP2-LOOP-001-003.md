# WP2 LOOP-001/002/003 — turn and step contracts

`sonder_runtime.application.loop_contract` defines immutable turn and step
state machines plus typed interception phases. A turn tracks admitted work and
accepted steering; a step models one model request and its resulting tool
execution lifecycle. Invalid transitions fail closed, and error/retry events
require explicit error metadata.

Evidence: `tests/test_loop_contract.py`, architecture/evidence gates, and
compileall.
