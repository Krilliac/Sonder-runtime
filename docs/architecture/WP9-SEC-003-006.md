# WP9 SEC-003–006: Filesystem, archive, and provenance safety

This slice establishes a non-mutating safety boundary for untrusted paths and
archives. Absolute paths, traversal, links, oversized entries, and excessive
aggregate expansion are rejected before extraction. Authorized-path validation
resolves the candidate twice and rejects symlink components; the eventual
writer must still use a no-follow or directory-handle based operation because
validation cannot make a later filesystem write atomic.

All imported content carries an explicit `ProvenanceLabel`, defaulting to
`untrusted`. ZIP and TAR metadata use the same bounded policy and do not read
member payloads during inspection.

Evidence: `tests/test_wp9_path_archive_safety.py`.
