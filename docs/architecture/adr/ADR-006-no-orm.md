# ADR-006: No ORM migration

**Status:** accepted

## Context

The stores use hand-written SQL with careful concurrency semantics
(compare-and-set claims, partial unique indexes, online backup).

## Decision

Keep raw `sqlite3` behind repository adapters. No SQLAlchemy or similar.

## Consequences

Repository adapters own all SQL; `sqlite3.connect` outside
`adapters/sqlite` (and the SPEC-2 root modules being strangled) fails
CI. Migrations remain explicit, checksummed Python modules — not
autogenerated diffs.
