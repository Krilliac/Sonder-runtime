# WP4 CTX-004/006/009/010 — context manifests

`context_manifest` provides deterministic content deduplication with provenance,
immutable last-good snapshots, stable prefix digests, and exact replay manifests
bound to model/native-context inputs. It is pure and does not mutate the
existing planner or context stores.

Evidence: `tests/test_context_manifest.py`, architecture/evidence gates, and
compileall.
