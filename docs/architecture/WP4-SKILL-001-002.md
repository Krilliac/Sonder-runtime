# WP4 SKILL-001/002 — Progressive skill discovery

This slice adds `sonder_runtime.application.skill_discovery`, independently of
the existing WP3 `sonder_runtime.application.skills` registry.

## Contract

- **SKILL-001:** `ProgressiveSkillRegistry` scans bundled, global, project, and
  configured roots in deterministic order. Later roots take precedence for a
  duplicate name; output is sorted by validated skill name. Missing roots and
  malformed manifests are ignored without preventing startup.
- **SKILL-002:** `discover()` returns only validated names and concise manifest
  descriptions. Full `SKILL.md` text is loaded only by the explicit
  `skill(name)` call.

Skill manifests use a small YAML-compatible front matter block with required
`name` and `description` fields. The registry does not execute skills, grant
trust, or modify the WP3 registry or existing loaders.

## Evidence

- `tests/test_wp4_skill_registry.py` covers precedence, deterministic sorting,
  validation, lazy progressive disclosure, and missing/malformed roots.
- Focused gate: `python -m pytest -q tests/test_wp4_skill_registry.py`.
- No specification checkbox, evidence-status file, commit, or push is part of
  this slice.
