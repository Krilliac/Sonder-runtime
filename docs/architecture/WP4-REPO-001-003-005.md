# WP4 REPO-001/003/005 — Repository intelligence index and map

This slice adds `sonder_runtime.application.repository_intelligence` as a
pure application projection. Discovery, parsing, Git, filesystem access, and
persistence remain adapter responsibilities; the module accepts records and
therefore has no filesystem scanning side effects.

## Contract

- **REPO-001:** `SymbolRecord` is a complete immutable symbol record. `IndexDelta`
  replaces records by stable `symbol_id` and removes deleted IDs atomically.
  `RepositoryIndex.replace_file` supports incremental per-file replacement.
- **REPO-003:** `ranked_map(query, token_budget=...)` returns deterministic
  `RankedRepositoryMap` entries. Direct name/signature matches rank above
  relationship matches, and selected record estimates never exceed the budget.
- **REPO-005:** every symbol carries `FileEvidence` with an exact lowercase
  SHA-256 digest and optional Git revision. Replacement records must carry the
  exact file evidence supplied by the caller. `digest_bytes` is a pure helper;
  it does not read files.

The implementation intentionally does not modify existing repository adapters,
the master specification checkboxes, or evidence status files.
