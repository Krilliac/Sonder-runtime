# WP8 API-001/002 — Shared event vocabulary and resumable streams

This slice establishes a transport-neutral `EventEnvelope` and `Snapshot` vocabulary,
then provides a bounded in-memory `ResumableStream` reference implementation. Event
sequences are stream-local and monotonic; event IDs are idempotent; snapshots advance
the replay base; and consumers resume from a watermark with optional bounded batches.
When retained history cannot satisfy a watermark, the stream reports a gap instead of
silently dropping events. Capacity exhaustion is explicit backpressure.

Evidence: `tests/test_wp8_protocol_streams.py` covers typing, monotonicity, snapshot
replay, duplicate suppression, bounded batching, backpressure, and gap detection.
