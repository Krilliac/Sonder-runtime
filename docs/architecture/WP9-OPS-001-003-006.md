# WP9 OPS-001/003/006 — Operations tracing and health

This slice adds a provider-neutral application boundary for operation context
correlation, structured tracing, operational health states, and bounded
telemetry. `BoundedTracer` accepts the existing `OperationContext` correlation
ID and exports only `TraceRecord` values that have passed recursive redaction,
attribute/label limits, a per-label cardinality limiter, and a final size cap.

Sensitive fields (prompt, messages, memory, secrets, credentials, artifacts,
and raw input/output) are replaced before export. Content export is an explicit
constructor choice and is not the default. The record shape is compatible with
OpenTelemetry concepts but does not impose an exporter dependency.

`HealthSnapshot` distinguishes liveness/readiness from dependency failure,
degraded capability, draining, and recovery-required state. It is a snapshot
contract only; probes and lifecycle ownership remain in their existing ports.

Validation: `tests/test_wp9_operations.py`, architecture/evidence gates,
`compileall`, and `git diff --check`.
