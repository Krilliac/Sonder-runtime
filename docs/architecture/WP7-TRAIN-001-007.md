# WP7 TRAIN-001–007 — Reproducible manifests and adapter catalog

This slice adds pure contracts for reproducible training inputs and outputs.
Dataset snapshots, base model artifacts, dependencies, and evaluation suites
carry immutable provenance. `ReproducibleTrainingManifest` requires the
evaluation dataset digest to equal the locked dataset snapshot and exposes a
stable SHA-256 digest over canonical JSON.

`AdapterCatalog` is copy-on-write and deterministic. It catalogs task, project,
and personalization adapters, preserves base-model compatibility, rejects
duplicate identities, and derives the same digest regardless of registration
order. Execution, persistence, promotion, and deployment remain behind the
existing training service and are intentionally outside this isolated slice.

Verification: `tests/test_wp7_training_catalog.py` plus architecture,
requirement-evidence, compile, and diff gates.
