# WP4 REPO-004/006/007 — navigation and expansion

`repository_intelligence.navigation` defines provider-neutral navigation
evidence and bounded symbol expansion across explicitly selected roots. It
does not invoke an LSP, scan a filesystem, or mutate an index; adapters can
later supply evidence from LSP or indexed sources with revision provenance.

Evidence: `tests/test_repository_navigation.py`, architecture/evidence gates,
and compileall.
