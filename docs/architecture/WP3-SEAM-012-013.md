# WP3 SEAM-012/013 — Artifact and telemetry contracts

## Boundary

Added the provider-neutral application ports
`sonder_runtime/application/ports/artifact_store.py` and
`sonder_runtime/application/ports/telemetry_sink.py`, plus the application
capability `RedactingTelemetrySink`.

`ArtifactHandle` is immutable metadata: an opaque id, byte count, SHA-256,
media type, and optional display name. It contains no path or payload. An
`AttachmentStore` owns completed attachments and only returns bounded reads.
`SpillStore` owns staged output; a `SpillHandle` can write only within its
`SpillSpec`, then commit exactly one immutable artifact or abort. Closing a
handle releases a capability; store cleanup and reaping remain authoritative.

`TelemetryEvent` is an immutable, bounded-shape envelope whose fields are
snapshotted. `RedactingTelemetrySink` recursively redacts text values before
calling its delegate and marks the exported event as redacted. Existing
persistence and observability adapters are not changed or wired to these
ports.

## Scope

This slice is additive. It adds only application ports, the redaction
capability, focused tests, and this evidence document. Concrete storage and
export adapters, retention policy, and composition wiring remain follow-up
work. No specification checkbox, evidence-ledger, commit, or push is part of
this slice.
