# WP9 SEC-001/002 — Credential broker and egress security

## Scope

The domain layer defines opaque, expiring credential handles and a pure
egress policy. The application broker stores secret values behind those
handles and releases them only for an authorized request.

## Security contract

- Handles contain no secret material and are scoped to normalized hosts and
  HTTP(S) protocols.
- Absolute URLs with userinfo, unsupported schemes, malformed ports, and
  non-allowlisted hosts are rejected.
- Literal loopback, link-local, and private-network destinations are denied by
  default. The policy performs no DNS or network I/O, so a resolver-aware
  transport must apply equivalent checks to resolved addresses.
- Redirect hops are independently checked and cannot widen credential scope.
- Expired or revoked handles cannot be reused.

## Verification

`tests/test_wp9_credential_egress.py` covers scoping, protocol enforcement,
private-network protections, redirect handling, expiry, and revocation.
