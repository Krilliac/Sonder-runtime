# Private prepared workbench invocation

`PreparedWorkbenchAdapter(runtime, policy_snapshot=...)` is a host-composition adapter. It exposes `prepare_workbench(request, admitted_context)` and `execute_prepared_workbench(prepared, admitted_context=..., managed_factory=...)`. Neither method is a model tool or public route. Preparation returns the existing immutable `PreparedWorkbenchRun`; execution returns the existing workbench terminal text, preserving managed controller evidence and escalation handling.

Preparation requires a live bounded context with exactly one canonical existing project directory, loaded runtime policy, and concrete configured tier bindings. It performs no provider generation, model discovery, or alias resolution. `spec.tier` preserves the normalized requested route; `resolved_model` and `model_ladder` record concrete choices. The actual runtime limit clamps requested steps to 20. Unknown/discovery-dependent target names are refused.

The required trusted `policy_snapshot` callback returns bounded JSON containing `allowed_tools`, `allow_web`, and `allow_location`, plus the host's relevant grant, catalog and configuration revisions. Do not include credentials. Tool names use the parent agent vocabulary and existing canonical aliases; child names such as `read_file` do not imply the parent `file_read` permission. The snapshot's canonical tool set is an enforced ceiling: caller allowlists intersect it, and the central dispatcher checks it independently. Existing permission gates still apply.

The digest binds the full resolved rung plan, runtime tier/policy and endpoint configuration, options, project, principal and context policy, and host policy snapshot. Execution compares current values before admission and callbacks and never substitutes a newly resolved plan. Changed policy, expired or cancelled context, nested invocation, or an unavailable private factory refuses execution. The private invocation expires on exit; captured callbacks cannot continue afterward. Managed sessions must preserve the admitted cancellation identity and cannot expand its roots or deadline. Transport flags must equal the prepared context exactly; attenuation requires a new preparation, so execution cannot retain a wider transport permission than the actual managed session.

This adapter does not establish authority from prepared JSON, authorize cloud use, create a durable dispatch lease, or deduplicate repeated host calls. The host must supply its reviewed managed factory and enforce durable one-shot work admission and final receipt linkage. There is no public execution endpoint in this slice. Tests use scripted model responses while executing the real local workbench/controller and filesystem paths; they do not establish live-provider performance or distributed guarantees.
